# 0.3.1の変更点

[English](0.3.1.md) | 日本語（正本）

0.3.1は、0.3.0以降に取り込んだ互換補正の追加と不具合修正を含みます。公開入口と利用方法は維持しています。

## 不具合修正

- `JSON.stringify`の入れ子呼び出しで外側の置換関数と字下げを保持します。配列形式の置換指定は数値・文字列とそのラッパーを変換し、指定順を保って重複を除きます。json2の取り込み元を固定し、独自修正を記録しました。
- インラインのソースマップURLは実際の行コメントだけを更新し、先行するinclude展開で追加された文字列・テンプレート・ブロックコメントを壊しません。
- `Object.hasOwn`はSymbolを返す通常のキー変換にも従い、無関係な取得処理を呼びません。
- 配列コピーは属性定義に対応する環境で自身のデータプロパティを作成し、継承された数値プロパティによる妨害を避けます。旧版を導入済みのエンジンも再判定して更新します。
- 正規表現による`split`で末尾の単語境界が空一致する場合を補正しました。

## 0.3.0以降に追加した補完と診断

`includes`、`padStart`・`padEnd`、`trimStart`・`trimEnd`と別名、`Object.entries`・`Object.values`、`flat`・`flatMap`、配列と文字列の`at`、`Object.hasOwn`、`toSorted`・`toReversed`・`toSpliced`、`findLast`・`findLastIndex`、`replaceAll`、`isWellFormed`・`toWellFormed`を補完します。正規表現の停止・誤判定の可能性を通知する診断も追加しています。

読み込みは同じエンジンの別スクリプトにも影響します。ES5・ES6の全機能やSymbol・Promise自体を追加するものではありません。`JSON.parse`の既知の制限は維持します。AE 26.5にはプロパティ属性の定義APIがないため、その環境での配列コピーは従来どおり代入を使います。詳細は[実行時補正](../../runtime/README.ja.md)と[ビルド時補正](../build-compatibility.ja.md)を参照してください。

## 検証範囲

Nodeで236試験と配布物からの導入を確認しました。AE 26.5x89 / ExtendScript 4.5.6では、[JSONの15項目×4条件](../evidence/2026-10-30/ae-26.5/json-stringify/results.json)と[所有判定38項目・配列コピー39項目×4条件](../evidence/2026-10-30/ae-26.5/compatibility-edge-cases/results.json)を確認済みです。Symbolと継承された属性の条件はNodeで確認し、AE実機の対応確認には含めません。旧AE、ほかのAdobe製品、新規エンジンへの全機能の初回導入は今回確認していません。
