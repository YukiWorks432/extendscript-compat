# Changes in 0.2.0

English | [日本語（正本）](0.2.0.ja.md)

Version 0.2.0 adds build-time compatibility fixes, opt-in runtime fixes for built-in functions, and UnitValue helpers. The expression-precedence protection and Rollup entry point from 0.1.0 remain available.

## Added fixes

- EC-03: Automatically add or reuse a label on the target loop for an unlabeled `continue` crossing a `switch`. Restore the semicolon required by ExtendScript after a labeled `continue` when minification removes it.
- EC-06: Convert `\x2D` and `\u002D` inside character classes in ES3 regular-expression literals to `\-`. Dynamically constructed `RegExp` objects are outside this transformation.
- EC-04, EC-05, EC-07, EC-08: Provide opt-in runtime fixes for known bugs in `parseInt`, `String.prototype.charAt`, `split`, and `replace`, using an es5-shim-derived implementation with ExtendScript-specific corrections for `split`. The other three functions use implementations tailored to the bugs observed on the host.
- EC-10, EC-11: Add `subtractUnitValues` and `isNull` to avoid incorrect host results when subtracting a UnitValue from a number or testing a UnitValue against `null`.

## Changes for consumers

Use `protectCompatibility` or the `extendscriptCompat` Rollup plugin to apply the additional build-time fixes. The existing `protectPrecedence` API continues to apply precedence protection only. The `extendscriptCompat` plugin, available since 0.1.0, now applies EC-03 and EC-06 fixes in addition to precedence protection.

```js
import "extendscript-compat/runtime";
import { isNull, subtractUnitValues } from "extendscript-compat/unit-value";

var distance = subtractUnitValues(10, new UnitValue(2, "in"));
var missing = isNull(distance);
```

Loading the runtime entry replaces built-in functions shared by the ExtendScript engine. Check the effect on other scripts using that engine. The UnitValue helpers require explicit changes at their call sites.

Node.js 22 or later is required. Rollup integration uses Rollup 4. Emit the runtime fixes as ES3 and apply compatibility protection last, including after minification. See the [build-time compatibility guide](../build-compatibility.md) and [runtime compatibility guide](../../runtime/README.md) for details.

GitHub and npm display the English README by default; Japanese is authoritative. The package includes both languages of the README, build guide, and runtime guide.

Release preparation verified 86 automated tests, the 17 packaged files, installation into an empty consumer, all four public entry points and type declarations, and minified and unminified Rollup output with source maps. The [package validation record](../evidence/release-0.2.0.json) contains hashes and checked items.

The [host validation results](../compatibility-host-validation.md) record 53 additional compatibility checks and 71 runtime checks passing for each minified and unminified output on After Effects 26.5x89 / ExtendScript 4.5.6. The outputs regenerated during release preparation have the same SHA-256 hashes as those host-tested outputs. Other Adobe products and older versions remain unverified.
