# Changes in 0.3.2

[日本語（正本）](0.3.2.ja.md) | English

0.3.2 updates dependencies, type documentation, and compatibility documentation. Public entry points, correction behavior, and the Node.js 22 or later requirement remain unchanged.

## Updates

- Updated the build-time dependency `magic-string` from 0.30.21 to 1.4.5. Generated code and source maps matched for 18 numeric-conversion inputs. See the [migration validation record](../evidence/2026-11-03/magic-string-1/README.ja.md).
- Expanded declarations and documentation for existing runtime compatibility APIs. The package now includes a [runtime API compatibility table](../../runtime/API-COMPATIBILITY.md) describing conditions and limitations.
- Updated build and validation dependencies, and added GitHub Actions that validate four environments and install the packed artifact into an empty consumer before npm publication.

## Validation scope

Validation covers Ubuntu and Windows with Node.js 22 and 24, public entries and types, normal and minified Rollup output and source maps, and bundled documentation and licenses.

The distributed runtime JavaScript is unchanged from 0.3.1. Adobe host tests were not repeated for this release; the confirmed conditions and limitations in [0.3.1's validation scope](0.3.1.md#validation-scope) still apply.
