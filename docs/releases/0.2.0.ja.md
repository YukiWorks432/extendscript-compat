# 0.2.0の変更点

[English](0.2.0.md) | 日本語（正本）

0.2.0では、ビルド時の互換補正を追加し、実行時の組み込み関数補正とUnitValue用の補助関数を提供します。0.1.0の式の優先順位補正とRollup用の入口は引き続き利用できます。

## 追加した補正

- EC-03：`switch`をまたぐ無名の`continue`に、対象ループのラベルを自動で追加または再利用します。圧縮後のラベル付き`continue`には、ExtendScriptが要求するセミコロンを補います。
- EC-06：ES3の正規表現リテラルで、文字クラス内の`\x2D`と`\u002D`を`\-`へ変換します。動的な`RegExp`の生成は対象外です。
- EC-04・05・07・08：`parseInt`、`String.prototype.charAt`、`split`、`replace`の既知の不具合を、明示的に読み込む実行時補正で対処します。es5-shim由来の実装にExtendScript固有の補正を加えています。
- EC-10・11：`subtractUnitValues`と`isNull`を追加しました。数値とUnitValueの減算、UnitValueと`null`の判定で、ホスト固有の演算結果を避けられます。

## 利用側の変更

ビルド時の追加補正は`protectCompatibility`またはRollupプラグインの`extendscriptCompat`から利用できます。既存の`protectPrecedence`と`extendscriptPrecedence`は、従来どおり優先順位の補正だけを行います。

```js
import "extendscript-compat/runtime";
import { isNull, subtractUnitValues } from "extendscript-compat/unit-value";

var distance = subtractUnitValues(10, new UnitValue(2, "in"));
var missing = isNull(distance);
```

実行時補正は読み込んだExtendScriptエンジンで共有される組み込み関数を置き換えます。同じエンジンを使うほかのスクリプトへの影響を確認してください。UnitValue用の補助関数は、呼び出し箇所を明示的に変更して使います。

Node.js 22以降が必要です。Rollup連携ではRollup 4を使用します。実行時補正はES3として出力し、最小化する場合も最後に互換補正を適用してください。詳しい使い方は[ビルド時の互換補正](../build-compatibility.ja.md)と[実行時の互換補正](../../runtime/README.ja.md)を参照してください。

## 文書と検証

GitHubとnpmでは英語のREADMEを標準表示とし、日本語版を正本とします。配布物には日英のREADME、ビルドガイド、実行時ガイドを含めます。

公開準備では86件の自動テスト、配布物17ファイルの確認、空の利用側への導入、4つの公開入口と型宣言、圧縮あり・なしのRollup出力とソースマップを検証しました。[配布物の検証記録](../evidence/release-0.2.0.json)にハッシュと確認項目を記録しています。

After Effects 26.5x89 / ExtendScript 4.5.6での[実機検証結果](../compatibility-host-validation.ja.md)には、圧縮あり・なしの各出力で追加補正53件と実行時補正71件の成功を記録しています。公開準備で再生成した出力は、その実機検証済み出力とSHA-256が一致しました。ほかのAdobe製品や旧版の動作は未検証です。
