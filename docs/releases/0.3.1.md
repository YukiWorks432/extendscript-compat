# Changes in 0.3.1

[日本語（正本）](0.3.1.ja.md) | English

0.3.1 includes compatibility additions and corrections merged since 0.3.0. Public entry points and usage remain unchanged.

## Fixes

- Nested `JSON.stringify` calls preserve the outer replacer and indentation. Array replacers accept numeric and string keys and their boxed forms, preserve order, and remove duplicates. The json2 upstream revision and local modifications are recorded.
- Inline source map URLs are updated only in actual line comments, preserving strings, templates, and block comments added by earlier include expansion.
- `Object.hasOwn` handles ordinary property-key conversion returning a Symbol and avoids unrelated getters.
- Array copying creates own data properties where descriptors are supported, bypassing inherited numeric properties. Earlier installations are checked again and updated when necessary.
- RegExp `split` handles a terminal empty word-boundary match correctly.

## Additions since 0.3.0

The runtime supplies `includes`, `padStart`/`padEnd`, `trimStart`/`trimEnd` and aliases, `Object.entries`/`Object.values`, `flat`/`flatMap`, array and string `at`, `Object.hasOwn`, `toSorted`/`toReversed`/`toSpliced`, `findLast`/`findLastIndex`, `replaceAll`, and `isWellFormed`/`toWellFormed`. Diagnostics for potential RegExp hangs and incorrect matches were also added.

Loading affects other scripts in the same engine. This is not complete ES5/ES6 support and does not add Symbol or Promise themselves. Existing `JSON.parse` limitations remain. AE 26.5 lacks property-descriptor APIs, so copying there continues to use assignment. See [runtime corrections](../../runtime/README.md) and [build-time compatibility](../build-compatibility.md).

## Validation scope

Validation covers 236 Node tests and installation from the packed artifact. Saved After Effects 26.5x89 / ExtendScript 4.5.6 results cover [15 JSON cases in four conditions](../evidence/2026-10-30/ae-26.5/json-stringify/results.json) and [38 ownership and 39 array-copy cases in four conditions](../evidence/2026-10-30/ae-26.5/compatibility-edge-cases/results.json). Symbol and inherited-descriptor cases were checked in Node, not AE. Older AE versions, other Adobe products, and first installation of all features in a fresh engine were not checked for this release.
