# 0.3.2の変更点

[English](0.3.2.md) | 日本語（正本）

0.3.2では、依存関係、型定義の説明、対応範囲の文書を更新しました。公開入口、補正の仕様、Node.js 22以降という利用条件は維持しています。

## 更新内容

- ビルド時の依存である`magic-string`を0.30.21から1.4.5へ更新しました。既存の数値変換を行う18種類の入力で、生成コードとソースマップの一致を確認しています。[移行時の検証記録](https://github.com/YukiWorks432/extendscript-compat/blob/c313a4c5305f947bfcf996d5ff743858aa4c6487/docs/evidence/2026-11-03/magic-string-1/README.ja.md)を参照してください。
- 実行時に補完する既存APIの型定義と説明を充実させました。補完の条件や制限を確認できる[実行時API対応表](../../runtime/API-COMPATIBILITY.ja.md)も同梱します。
- ビルド・検査用の依存関係を更新し、npm公開前に4環境の検証、梱包した配布物の導入確認を行うGitHub Actionsを追加しました。

## 検証範囲

検証は、Ubuntu・WindowsとNode.js 22・24の組み合わせ、公開入口と型定義、通常・圧縮時のRollup出力とソースマップ、同梱文書・ライセンスを対象とします。

配布する実行時のJavaScriptは0.3.1から変更していません。今回の版ではAdobe実機の再検証を行っておらず、確認済みの条件と未確認事項は[0.3.1の検証範囲](0.3.1.ja.md#検証範囲)を引き継ぎます。
