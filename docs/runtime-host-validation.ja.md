## JSON・ES5・ES6補完の実機確認

2026年10月27日、After Effects 26.5x89 / ExtendScript 4.5.6（build 80.1060872）で統合後の実行時コードを確認した。通常版と圧縮版のどちらも、ポリフィル22項目と既存の4関数補正71項目が成功した。再読み込み後の22項目と関数の同一性も確認した。移行元テンプレートのテストは48項目すべて成功した。さらにテンプレートの一時コピーで`init`を単一の`/runtime`読込へ変更し、全4スクリプトのビルドと型検査を実行した。結果表示だけを変更したテストの実ビルド出力も実機で48項目すべて成功した。

最初の実行では、既存の`JSON.parse`が変換用コールバックを無視し、22項目中1件が失敗した。`JSON.stringify`も同様だったため、不完全なJSON関数を検出して補完版へ置き換える処理を追加した。

修正済み版の通常版と圧縮版は、まず初回のポリフィル導入後の同じ共有エンジンで検証した。統合用マーカーは解除したが、ES5・ES6のキャッシュと既存の関数は残っていた。その後After Effectsを再起動し、4つのマーカーとキャッシュが存在しない状態から通常版を初めて適用して、22項目と71項目、再読み込みを再確認した。圧縮版は未導入エンジンでの初回適用を確認していない。各検証でプロジェクトの項目数と変更状態は変化していない。

[検証結果と生成物のハッシュ](evidence/polyfills-ae-26.5.json)を記録している。`node scripts/build-host-polyfill-probe.mjs`で圧縮版とテンプレートテストを再生成できる。
