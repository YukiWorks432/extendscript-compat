## 原記録の参照

[整理前の全記録](https://github.com/YukiWorks432/extendscript-compat/tree/c313a4c5305f947bfcf996d5ff743858aa4c6487/docs/evidence)は、コミット `c313a4c5305f947bfcf996d5ff743858aa4c6487` に固定しています。JSON、検証時のJSX、比較用スクリプトは当時の内容のまま参照できます。これは記録を保存していたコミットであり、すべての検証をそのコミットで実施したことを示しません。実際の対象コミットや生成物ハッシュは、それぞれの記録に従います。

通常のチェックアウトには、重複する全量ログと生成済みコードを展開しません。自動テストが使う2件の正規表現の実機結果は、[テスト用資料](../../test/fixtures/regexp-host-results/README.md)へ内容を変えず移しています。Gitの履歴は維持しているため、この整理は現行ツリーの削減です。

## 今後残す情報

検証結果は該当する実機検証文書・変更案内へ要約し、この案内から参照します。日付、対象コミット・生成物、環境、実施条件、成否、既知の制限と必要な代表ハッシュを記録してください。空の失敗一覧、同じ契約の繰り返し、全スクリプトのハッシュ一覧、生成したJSXの複製は追加しません。判断に必要な失敗入力や実際の出力差は省略せず、再現に使う資料はtest/fixtures/など用途に対応する場所で管理します。
